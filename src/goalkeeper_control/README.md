# Goalkeeper Control

The fixed diamond and rectangle slide as one assembly. The planner checks the real projected rhombus and occupied lower shapes, tests swept clearance and enforces the time budget. Run `python3 run_keeper.py demo --case low` or export the path with `--path-csv action_path.csv`.

See the [active interfaces](../../docs/interfaces.md) and [design and validation](../../docs/robot-design.md).
